# Multimodal Construction Intelligence Platform

AI-assisted construction safety, crack detection, valuation, planning and weather advisory.

## Run
- Frontend demo: open index.html
- Backend: cd backend; pip install -r requirements.txt; uvicorn main:app --reload
- API docs: http://127.0.0.1:8000/docs

## Stack
React/HTML frontend, FastAPI backend, OpenCV, LLM + vision (extendable)
